# Методология STAR и Подготовка к Собеседованию в 3 Блока

Стандарт подготовки к интервью SuperJob Pro разделяет собеседование на 3 обязательных блока.

---

## Блок 1: Технический скрининг (10 вопросов)
Подготовка охватывает фундаментальные вопросы по ключевым темам стека вакансии:
1. **Python**: Модель памяти, GIL, генераторы, декораторы, асинхронность (`async`/`await`), контекстные менеджеры (`with`).
2. **Базы данных & SQL**: Уровни изоляции транзакций (Read Uncommitted, Read Committed, Repeatable Read, Serializable), индексы (B-Tree, Hash), EXPLAIN ANALYZE, внешние ключи, нормализация (1НФ, 2НФ, 3НФ).
3. **Web & Архитектура**: Архитектурные принципы REST, методы HTTP (GET, POST, PUT, PATCH, DELETE), статус-коды (200, 201, 400, 401, 403, 404, 500), Stateless.
4. **Linux & Сети**: Nginx как reverse proxy, systemd сервисы, логирование, DNS, порты, права доступа к файлам.

---

## Блок 2: Поведенческие вопросы (STAR-метод)

Формула STAR:
- **S (Situation)**: Какая возникла исходная ситуация / контекст?
- **T (Task)**: Какая задача стояла лично перед вами?
- **A (Action)**: Какие конкретные действия вы предприняли (инструменты, логика, преодоление трудностей)?
- **R (Result)**: Измеримый результат (что заработало, сколько времени сэкономило, чему научились).

### 1. Elevator Pitch (Самопрезентация за 90 секунд)
- **Кто я**: «Здравствуйте! Меня зовут Дмитрий Турейко. По профильному образованию я специалист по информационным системам (СПО МТИ). Мой основной фокус — бэкенд-разработка на Python и проектирование баз данных».
- **Что умею и сделал**: «Создал и развернул в продакшене веб-сервис gorizont-blog.ru на Ubuntu Server с Nginx, написал проект clinic_connect со сложной схемой реляционной БД в PostgreSQL и автоматизировал интеграции с AI API».
- **Чего хочу**: «Ищу позицию Junior/Trainee Python-разработчика, где смогу взять на себя рутинные задачи команды (написание эндпоинтов, багфиксы, интеграции) и развиваться под руководством сильных коллег».

### 2. Сложная задача / баг по STAR:
- **S**: «При развертывании gorizont-blog.ru на Linux сервере возникла проблема с доступностью медиафайлов и SSL-сертификатом при проксировании через Nginx».
- **T**: «Нужно было настроить безопасный HTTPS доступ и правильную отдачу статики без перегрузки основного веб-процесса».
- **A**: «Я настроил конфигурационный файл Nginx с корректным блоком `location /media/`, оптимизировал заголовки кэширования и перевыпустил сертификат через Certbot».
- **R**: «Сервис работает стабильно со 100% доступностью по HTTPS, среднее время ответа страницы снизилось до 120 мс».

### 3. Аргументация зарплаты (50 000 – 60 000 ₽):
- «Моя планка — 50 000 – 60 000 рублей на руки. Она полностью соответствует рынку начинающих разработчиков в РФ, учитывает профильное образование СПО МТИ и реальный опыт развертывания рабочих проектов, а не только решения учебных задач на курсах».

## Блок 3: Вопросы работодателю (Повышают конверсию в оффер)
Никогда не отвечать «Вопросов нет». 3–4 зрелых вопроса показывают инженерную осознанность:
1. «Как у вас устроен процесс онбординга джуниора: есть ли выделенный наставник или ментор на испытательный срок?»
2. «Как выглядит стандартный цикл задачи: есть ли код-ревью перед мержем в main и автоматический CI/CD?»
3. «Какие приоритетные задачи команда планирует закрыть в первую очередь силами нового разработчика?»
4. «Каковы критерии успешного прохождения испытательного срока?»
