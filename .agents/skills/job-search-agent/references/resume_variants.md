# 3 Функциональных резюме Дмитрия Турейко под карьерные треки

Функциональная модель резюме устраняет непрофильный информационный шум, фокусирует внимание работодателя на профильном СПО МТИ и практических проектах.

---

## 1. Резюме 1: Junior Python / Web Developer (Full-time Remote)
- **Целевая позиция**: Junior Python Developer / Младший веб-разработчик
- **Формат**: Полный рабочий день (Full-time), 100% удалённая работа (РФ)
- **Зарплатные ожидания**: 50 000 – 60 000 ₽ / месяц
- **Ключевой профиль**:
  Разработка серверной части веб-приложений, REST API, взаимодействие с реляционными базами данных PostgreSQL/SQLite, автоматизация рутинных задач бэкенда, интеграция со сторонними сервисами.
- **Стек**: Python 3, FastAPI, Django, PostgreSQL, SQL, REST API, Git, Linux (Ubuntu), Nginx
- **Проекты в резюме**:
  - **gorizont-blog.ru**: полнофункциональный production-блог с деплоем на Linux и Nginx.
  - **clinic_connect**: веб-сервис управления клиникой с реляционной структурой данных.
  - **AI Automation**: интеграция OpenAI и Gemini API для автогенерации и аналитики.

---

## 2. Резюме 2: Junior Web Developer (Part-time / Проектная разработка)
- **Целевая позиция**: Младший веб-разработчик / Python скриптер (Part-time / проектно)
- **Формат**: Неполный день (4–5 часов в день), гибкий график, спринты
- **Зарплатные ожидания**: 25 000 – 35 000 ₽ / месяц (или по проектной оценке)
- **Ключевой профиль**:
  Решение конкретных прикладных задач бизнеса: разработка Telegram-ботов, парсеров данных (hh.ru, сайты поставщиков), микросервисов автоматизации, верстка и интеграция компонентов.
- **Стек**: Python, aiogram, BeautifulSoup, aiohttp, SQLite, JavaScript, HTML5, CSS3, Tailwind CSS, REST API
- **Фокус пользы**: Быстрое закрытие локальных задач без длительного онбординга.

---

## 3. Резюме 3: Стажёр-разработчик (Intern / Trainee / Корпоративные программы)
- **Целевая позиция**: Стажёр-разработчик (Intern / Trainee Python & Web)
- **Формат**: Стажировка с обучением и менторством, удалённо
- **Зарплатные ожидания**: «Не указана» (по условиям корпоративной программы)
- **Ключевой профиль**:
  Академическая и практическая база СПО МТИ «Информационные системы». Высокая обучаемость стандартам разработки компании, снятие монотонной рутины со старших разработчиков (написание тестов, документирование API, фикс багов, рефакторинг простых модулей).
- **Стек**: Python, Базовые алгоритмы и структуры данных, SQL (реляционные базы данных), Git, Linux, ООП
- **Готовность**: Прохождение любого вводного тестирования и тестовых заданий.
